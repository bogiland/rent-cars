HOW TO ADD REAL CAR PHOTOS
==========================

1. Find a real photo of the car (search: "<brand> <model> <year>").
2. Rename the file to the SLUG shown below + extension (.jpg/.png/.webp).
   Example: bmw-x6-2024.jpg
3. Drop it into this folder (public/cars/local/).
4. Restart dev (pnpm dev) OR run: pnpm run photos
   The photo appears automatically on that car everywhere.

Landscape photos ~1200px wide look best. One photo per car.
